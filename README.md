# 数学工具箱 (Math Toolbox)

一个功能强大的在线数学工具箱，支持基础计算、代数工具、几何绘图和统计分析。

## 功能特点

### 基础计算
- 科学计算器
- 单位转换
- 进制转换
- 百分比计算
- 分数计算

### 代数工具
- 方程求解器
- 因式分解
- 多项式运算
- 函数绘图
- 矩阵运算

### 几何工具
- 交互式几何绘图（类似 GeoGebra）
- 平面几何绘图
- 立体几何绘图
- 几何图形计算
- 坐标转换

### 统计与概率
- 数据统计分析
- 概率计算
- 统计图表生成

### 多语言支持
- 中文
- English

## 技术栈

- HTML5
- CSS3
- JavaScript (ES6+)
- Bootstrap 5
- MathJax 3
- Chart.js 4
- D3.js 7

## 快速开始

1. 克隆或下载项目
2. 在浏览器中打开 `index.html`

```bash
# 或者使用本地服务器
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 使用说明

### 基础计算
1. 从左侧导航栏选择"基础计算"
2. 选择具体功能（计算器、单位转换等）
3. 输入数值并查看结果

### 几何绘图
1. 从左侧导航栏选择"几何工具"
2. 使用工具栏选择绘图工具（点、线、圆、多边形等）
3. 在画布上点击或拖拽进行绘图
4. 支持缩放和平移操作

### 函数绘图
1. 在输入框中输入函数表达式（如：y = x^2）
2. 点击"绘图"按钮查看函数图像
3. 支持多个函数同时绘图

### 统计分析
1. 输入数据序列
2. 选择要进行的统计操作
3. 查看统计结果和图表
